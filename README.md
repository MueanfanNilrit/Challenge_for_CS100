# Challenge G13
วิธีทดลอง Challenge
Challenge เป็นเกม Memory Card Game ที่ให้ผู้เล่นเปิดไพ่และจับคู่ไพ่ที่เหมือนกันภายในเวลาที่กำหนด
1. เข้า Challenge
สแกน QR Code ที่กำหนดเพื่อเข้าสู่หน้า Challenge
สามารถใช้กล้องโทรศัพท์สแกน QR Code เพื่อเข้าสู่ Web App ได้
2. เล่น Memory Card Game
เมื่อเข้าสู่หน้า Challenge แล้ว ให้คลิกไพ่ 2 ใบ เพื่อเปิดดูและพยายามจับคู่ไพ่ที่มีรูปเหมือนกัน
ผู้เล่นต้องจับคู่ไพ่ให้ถูกต้อง
มีเวลาจำกัด 35 วินาที
สามารถเปิดไพ่ทีละ 2 ใบเพื่อค้นหาคู่ที่ตรงกัน
3. รับ Portfolio Item JSON
เมื่อหมดเวลา ระบบจะแสดง Portfolio Item JSON ที่เกิดจากการเล่น Challenge
JSON ที่ได้รับจะแสดงข้อมูลของผลการเล่น และสามารถนำไปใช้กับระบบ Portfolio ได้
4. Copy หรือ Download JSON
หลังจากได้รับ Portfolio Item JSON แล้ว สามารถเลือกได้ 2 วิธี
กด Copy JSON เพื่อคัดลอกข้อมูล JSON
กด Download .json เพื่อดาวน์โหลดไฟล์ JSON
จากนั้นสามารถนำ Portfolio Item JSON ที่ได้ไปใช้สำหรับการ Import Portfolio Item ในระบบต่อไป
